# Salona website

Landing page and apply form for the Salona Founding 10 programme in Riyadh.

- index.html: landing page
- apply.html: apply form (saves to Google Sheet when SHEET_URL is set, then offers WhatsApp)
- terms.html, privacy.html, founding-10.html: placeholders until the lawyer-approved text is ready
- tools/google-sheet-script.gs: Apps Script that saves applications to a Google Sheet
